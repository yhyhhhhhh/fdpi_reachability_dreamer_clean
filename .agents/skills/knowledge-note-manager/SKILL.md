# knowledge-note-manager

## 作用

创建和维护 `notes/` 下的知识笔记，使理论、实验分析、问题、版本、文献和方法比较可以通过双链组织。

## 适用场景

- 用户要求整理理论或知识。
- 用户要求把实验结果上升为分析笔记。
- 用户要求写问题复盘。
- 用户要求整理文献笔记。
- 用户要求比较不同方法。
- 用户希望形成 Obsidian/Foam 风格链接。

## 不适用场景

- 不用于保存原始实验日志、图片、checkpoint。
- 不用于替代 `experiments/` 中的 `实验记录.md`。
- 不用于直接修改代码。

## 固定路径

笔记默认放在：

```text
notes/
  概念/
  理论/
  实验分析/
  问题/
  版本/
  想法/
  文献/
  方法比较/
```

## 笔记边界

- `experiments/实验记录.md`：记录实验事实。
- `notes/实验分析/*.md`：解释实验结果说明了什么。
- `notes/理论/*.md`：整理理论机制。
- `notes/问题/*.md`：追踪长期问题。
- `notes/版本/*.md`：记录版本目标、差异、代表实验。

## 操作流程

1. 判断笔记类型：概念、理论、实验分析、问题、版本、想法、文献、方法比较。
2. 在对应目录创建中文 Markdown 笔记。
3. 使用 `[[双链]]` 链接相关概念、问题、版本或实验分析。
4. 如果是实验分析，必须链接到对应 `experiments/.../实验记录.md`。
5. 如有必要，更新 `notes/主页.md` 或 `notes/项目地图.md`。
6. 配合 `knowledge-link-maintainer` 检查孤立笔记。

## 模板：实验分析笔记

```md
# <实验分析标题>

关联实验：
- [实验记录](../../experiments/<实验目录>/实验记录.md)

关联问题：
- [[问题名称]]

关联版本：
- [[版本名称]]

关联概念：
- [[概念名称]]

## 观察

## 解释

## 对后续实验的影响

## 下一步链接
```

## 完成标准

- 笔记已放入正确目录。
- 笔记内容使用中文。
- 重要笔记至少包含 2 个相关链接。
- 实验分析笔记链接到对应实验记录。

## 禁止事项

- 不要把原始日志、图片、checkpoint 复制进 notes。
- 不要创建没有任何链接的孤立笔记。
- 不要把一次性流水账写成理论笔记。
- 不要把实验记录和实验分析混为同一个文件。
