# experiment-report-writer

## 作用

根据实验目录中的日志、指标、图片和命令信息，撰写结构统一、中文优先、带关键图片的 `实验记录.md`。

## 适用场景

- 某次实验已经跑完，需要整理实验结果。
- 已有日志、图片、指标，需要生成实验记录。
- 需要补全或重写 `实验记录.md`。
- 需要将关键图片自动插入实验报告。

## 不适用场景

- 不用于新建完整实验目录结构。
- 不用于审查算法理论是否正确。
- 不用于撰写论文正文。

## 输入

优先读取实验目录中的：

- `实验清单.yaml`
- `运行命令.sh`
- `配置.yaml`
- `参数说明.md`
- `指标结果.json`
- `图片/`
- `日志/`
- 已存在的 `实验记录.md`

## 图片插入规则

当 `图片/` 中存在图片时：

1. 优先插入关键结果图。
2. 普通实验建议插入 2～4 张图。
3. 对比实验可插入 3～6 张图。
4. 每张图下方应尽量补一句简短中文说明。

优先级建议如下：

1. 总奖励/目标指标曲线。
2. 安全代价/约束指标曲线。
3. 成功率曲线。
4. 核心对比图。
5. 与问题定位直接相关的损失曲线。

## 标准输出结构

`实验记录.md` 应尽量包含以下结构：

1. 实验标题。
2. 实验目的。
3. 实验背景（可选）。
4. 实验配置。
5. 代码修改（如有）。
6. 核心结果。
   - 训练曲线/关键图片。
   - 关键指标。
7. 结果分析。
8. 主要问题。
9. 初步结论。
10. 下一步计划。

## 操作流程

1. 读取实验目录中的基础信息。
2. 汇总实验目的、运行命令、配置来源。
3. 扫描 `图片/` 并挑选关键图片。
4. 从指标文件或日志中提取关键指标。
5. 按统一中文模板撰写 `实验记录.md`。
6. 插入图片及简短中文说明。
7. 若信息缺失，应明确写出“待补充”而不是省略整节。

## 完成标准

- `实验记录.md` 已更新。
- 关键图片已插入，并有简短中文说明。
- 运行命令、配置、指标、结论都有可追踪来源。

## 输出要求

- 已更新的 `实验记录.md` 路径。
- 插入了哪些图片。
- 提取了哪些关键指标。
- 哪些字段仍待补充。

## 禁止事项

- 不要只贴图片不写分析。
- 不要只写结论不写实验配置。
- 不要堆很多图片但没有筛选。
- 不要把与实验无关的图片全部插入。
- 不要把实验报告写成纯英文，除非用户明确要求。
