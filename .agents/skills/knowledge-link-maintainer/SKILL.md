# knowledge-link-maintainer

## 作用

维护 `notes/` 知识网络中的链接关系，避免笔记孤立，使理论、实验、问题、版本和文献可以互相调用。

## 适用场景

- 新建知识笔记后。
- 新增实验分析笔记后。
- 新增问题、版本、概念笔记后。
- 用户要求整理笔记链接。
- 用户要求检查孤立笔记。

## 不适用场景

- 不用于整理实验原始文件。
- 不用于写实验报告。
- 不用于代码审查。

## 固定维护文件

- `notes/主页.md`
- `notes/项目地图.md`

## 链接规则

- 默认使用 `[[双链]]` 表示知识内部链接。
- 指向实验工件时使用普通 Markdown 相对路径链接。
- 每个重要笔记至少应有：
  - 1 个上级索引链接。
  - 1 个相关内容链接。

## 操作流程

1. 扫描新增或修改的 notes 文件。
2. 检查是否存在相关概念、理论、实验分析、问题、版本、文献笔记。
3. 为新笔记补充 2～5 个相关 `[[双链]]`。
4. 更新 `notes/主页.md` 的入口链接。
5. 更新 `notes/项目地图.md` 的主题链接。
6. 检查实验分析笔记是否链接到对应 `experiments/.../实验记录.md`。
7. 输出潜在孤立笔记清单。

## 完成标准

- 新笔记至少有合适的上级入口。
- 重要笔记不是孤立节点。
- 项目地图能看到新笔记的归属。
- 实验分析能回到原始实验目录。

## 禁止事项

- 不要为了增加链接而添加无关链接。
- 不要把所有笔记都链接到主页而缺少主题关系。
- 不要用普通 Markdown 链接替代内部知识双链，除非链接对象是实验工件或外部文件。
