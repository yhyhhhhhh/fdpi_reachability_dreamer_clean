# experiment-command-manager

## 作用

将冗长的一次性终端命令整理成可维护、可复现、可记录的实验运行结构。

核心原则：不要把长命令作为唯一实验入口。长命令应拆分为：

1. `运行命令.sh`
2. `配置.yaml`
3. `参数说明.md`
4. `实验清单.yaml` 中的命令记录

## 适用场景

当出现以下情况时使用：

- 用户要求运行实验，且命令参数较多。
- Codex 准备生成很长的终端命令。
- 用户要求保存实验命令。
- 用户要求解释每个参数含义。
- 用户希望后续方便修改实验参数。
- 命令超过 120 个字符。
- 命令包含超过 5 个显式参数。
- 命令包含较多路径、seed、学习率、环境数量、日志路径或 checkpoint 路径。

## 不适用场景

- 不用于分析实验结果。
- 不用于判断算法设计。
- 不用于普通短命令，例如 `pytest tests/test_x.py`。
- 不用于一次性查看文件、列目录、git status 等简单命令。

## 固定路径

如果命令属于某次实验，应写入对应实验目录：

```text
experiments/YYYY-MM-DD_中文实验名称/
  运行命令.sh
  配置.yaml
  参数说明.md
  实验清单.yaml
```

如果实验目录尚不存在，应建议或配合 `experiment-archive-manager` 创建实验目录。

## 文件职责

### `运行命令.sh`

保存实际可执行命令。

要求：

- 使用 bash 脚本。
- 开头包含 `#!/usr/bin/env bash`。
- 使用 `set -e`。
- 尽量只保留短命令。
- 优先使用 `--config <配置文件路径>`。
- 如果训练入口暂不支持 config，则使用多行反斜杠拆分命令。

推荐格式：

```bash
#!/usr/bin/env bash
set -e

python train.py \
  --config experiments/YYYY-MM-DD_中文实验名称/配置.yaml
```

### `配置.yaml`

保存实验参数。

推荐结构：

```yaml
实验:
  名称:
  日期:
  输出目录:

运行:
  seed:
  num_envs:
  device:

训练:
  total_steps:
  batch_size:
  learning_rate:

日志:
  log_dir:
  checkpoint_dir:
  use_wandb:
```

### `参数说明.md`

用中文解释重要参数。

推荐结构：

```md
# 参数说明：<实验名称>

## 运行参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|

## 训练参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|

## 日志参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
```

### `实验清单.yaml`

应记录运行命令入口：

```yaml
command: bash experiments/YYYY-MM-DD_中文实验名称/运行命令.sh
config: experiments/YYYY-MM-DD_中文实验名称/配置.yaml
parameter_note: experiments/YYYY-MM-DD_中文实验名称/参数说明.md
```

## 操作流程

1. 检查即将生成或用户提供的命令是否过长。
2. 如果超过 120 字符或超过 5 个参数，不要只输出长命令。
3. 确定该命令所属实验目录。
4. 创建或更新 `运行命令.sh`。
5. 将参数整理进 `配置.yaml`。
6. 将重要参数含义写入 `参数说明.md`。
7. 在 `实验清单.yaml` 中记录短命令入口。
8. 在最终回复中只给出短命令。
9. 如果训练代码不支持 `--config`，应保留多行脚本，并建议后续将入口改造为 config 驱动。

## 完成标准

- 不再需要复制一长串终端命令。
- 实验目录中存在 `运行命令.sh`。
- 实验目录中存在 `配置.yaml`。
- 重要参数已写入 `参数说明.md`。
- `实验清单.yaml` 中记录了运行入口。
- 用户后续可以通过修改 `配置.yaml` 调整实验。

## 输出要求

```text
运行命令：
bash experiments/YYYY-MM-DD_中文实验名称/运行命令.sh

已创建或更新：
- 运行命令.sh
- 配置.yaml
- 参数说明.md
- 实验清单.yaml

参数说明：
- 详见 参数说明.md
```

## 禁止事项

- 不要默认输出一整行超长命令作为唯一运行方式。
- 不要只保存命令而不解释参数。
- 不要把日志、checkpoint、输出目录写到实验目录外，除非用户明确要求。
- 不要把不同实验共用同一个输出目录。
- 不要用 `exp1`、`test_run` 这类难以理解的实验目录名。
- 不要省略 `参数说明.md`。
