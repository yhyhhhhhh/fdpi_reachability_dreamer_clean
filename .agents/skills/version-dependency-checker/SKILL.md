# version-dependency-checker

## 作用

检查新版本是否仍然隐式依赖旧版本，避免结构不干净、后续维护困难。

## 适用场景

- 新版本刚建立。
- 新版本完成较大修改后。
- 需要确认新旧版本是否独立。
- 用户要求检查版本隔离情况。

## 检查内容

重点检查：

1. 新版本代码中是否直接 import 旧版本核心实现。
2. 新版本配置中是否仍指向旧版本类路径。
3. 新版本运行脚本是否仍使用旧版本输出目录。
4. 新版本日志或 run_name 是否仍沿用旧版本命名。
5. 是否存在本应共享却没有抽到 `common/` 的复用代码。

## 操作流程

1. 扫描新版本目录中的 import。
2. 检查配置文件中的路径与类名。
3. 检查输出目录与日志目录。
4. 汇总潜在旧依赖项。
5. 给出简洁中文检查报告。

## 命令模板

如果仓库中存在检查脚本，可使用：

```bash
python scripts/checks/check_version_dependency.py --target <新版本目录> --old <旧版本标识>
```

## 输出要求

输出应尽量采用中文，包含：

- 检查对象。
- 发现的问题。
- 风险说明。
- 建议处理方式。

## 禁止事项

- 不要展开算法理论讨论。
- 不要在没有证据的情况下推测大量问题。
- 不要忽略明显的旧版本路径残留。
