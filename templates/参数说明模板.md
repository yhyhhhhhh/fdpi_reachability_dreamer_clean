# 参数说明：实验名称

## 运行参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| seed |  | 随机种子，用于控制实验复现 | 多 seed 对比时改为 0、1、2 |
| num_envs |  | 并行环境数量 | 显存不足时降低 |
| device |  | 使用的计算设备 | 多卡实验时修改 |

## 训练参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| total_steps |  | 总训练步数 | 快速测试时可降低 |
| batch_size |  | 每次更新使用的 batch 大小 | 显存不足时降低 |
| learning_rate |  | 学习率 | 训练不稳定时优先检查 |

## 日志参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| log_dir |  | 日志保存目录 | 不建议手动改到实验目录外 |
| checkpoint_dir |  | 模型检查点保存目录 | 每个实验应独立 |
| use_wandb |  | 是否启用 wandb | 需要在线记录时开启 |
