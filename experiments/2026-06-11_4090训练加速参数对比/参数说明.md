# 参数说明：4090训练加速参数对比

## 运行参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| training_config | configs/reachability_gp_isaaclab22_4090_fast.yaml | 默认测试 4090 fast 训练配置 | baseline/balanced/fast 分别见对应配置文件 |
| num_envs | 128 | IsaacLab 并行环境数量 | 4090 24GB 优先 128；OOM 时回退 64 |
| device | cuda:0 | 单卡 4090 | 多卡未适配 |
| wandb_mode | disabled | profiling 只写本地文件 | 正式长训可改 online |

## 训练参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| batch_size | 256 | world model / risk critic batch | 必须 >= num_envs 且能被 num_envs 整除 |
| imagine_batch_size | 256 | 主策略 imagined rollout batch | 必须 >= num_envs 且能被 num_envs 整除 |
| batch_length | 64 | replay 序列长度 | 保持与默认一致 |
| train_every | fast 等效 1024 env steps | 降低更新/采样比例 | 若学习不足，先恢复 Gp/Gd update 到 2 |
| update_steps | WM/agent=2, Gp/Gd/dual=1 | 单次触发的更新次数 | fast 优先吞吐，balanced 更保守 |
| TF32 | true | 允许 4090 使用 TF32 matmul | 若数值异常可关闭 |

## Profiling 参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| warmup_env_steps | 32768 | 预热步数，不计入正式吞吐 | 长测可提高到 51200 |
| rollout_iters | 1024 | fast 统计 1024 个 vectorized step，即 131072 env steps | baseline 用 2048 以保持同等 env steps |
| update_every_iters | 8 | fast 每 8 个 vectorized step 更新一次 | 与 1024 env steps 对齐 |
| measure_checkpoint | false | profiling 不测 checkpoint | 需要 IO 指标时改 true |

## 注意事项

- `配置.yaml` 是 fast 单组入口。
- `配置_fast.yaml` 是三组对比脚本使用的 fast overlay，会把输出写入 `对比结果/fast`。
- `配置_balanced.yaml` 和 `配置_baseline.yaml` 复用主配置，仅覆盖差异，并分别写入 `对比结果/balanced` 和 `对比结果/baseline`。
- `运行全部对比.sh` 会顺序执行 baseline、balanced、fast，耗时较长。
- 正式长训前建议先看三组 profiling 的 `指标结果.json` 和 `实验记录.md`，确认 fast 没有 OOM、NaN 或 replay assertion。
