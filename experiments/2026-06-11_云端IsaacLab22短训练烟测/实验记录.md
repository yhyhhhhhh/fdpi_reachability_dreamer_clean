# 云端IsaacLab22短训练烟测

## 实验目的

验证 `fdpi-1` 云端服务器上的 IsaacLab 2.2.1 / IsaacSim 5.0 环境、`surgical_robot5` 任务扩展和 FDPI Reachability Dreamer IsaacLab22 迁移版本可以完成小规模训练闭环。

## 运行环境

- 远端主机：`fdpi-1`
- GPU：RTX 4090 24GB
- IsaacLab：`/root/IsaacLab`
- conda 环境：`isaaclab`
- 项目目录：`/root/gpufree-data/fdpi_reachability_dreamer_clean`
- SurgicalRobot5 目录：`/root/gpufree-data/surgical_robot5`

## 运行命令

```bash
bash experiments/2026-06-11_云端IsaacLab22短训练烟测/运行命令.sh
```

## 关键配置

- `NumEnvs: 2`
- `SampleMaxSteps: 1024`
- `BufferWarmUp: 64`
- `BatchSize: 8`
- `BatchLength: 16`
- `ImagineHorizon: 5`
- `Wandb.Mode: disabled`

## 结果

- 状态：已完成。
- 远端静态检查通过：`python -m compileall fdpi_reachability_dreamer_isaaclab22`、`python -m unittest tests.test_isaaclab22_package`、`import surgical_robot5` 均成功。
- 0 步 IsaacLab 检查通过：远端可创建 `SurgicalRobot5-HeadPipe-GraspGoalDreamerForce-OSC-RL-Direct-v1` 环境，`NumEnvs=2`。
- 短训练烟测通过：`SampleMaxSteps=1024`、`NumEnvs=2`，进度条完成 `512/512`，日志显示约 `19.51 it/s`。
- 已保存 checkpoint 到 `检查点/fdpi-cloud-isaaclab22-smoke/cloud_smoke/`，包含 step 0 和 step 512 的 world model、agent、Gp/Gd、dual policy 与 full state。
- 已为 `surgical_robot5` 补充最小 `pyproject.toml` 并同步远端，远端 `python -m pip install -e /root/gpufree-data/surgical_robot5/exts/surgical_robot5` 已验证通过。

## 观察

- 训练主链路已经能在 fdpi-1 的 IsaacLab 2.2.1 / IsaacSim 5.0 环境下闭环运行，说明远端 `surgical_robot5` 任务注册、IsaacLab22 wrapper、训练入口、配置覆盖和 checkpoint 保存链路均可用。
- 初次 editable 安装失败原因是 `setup.py` 顶层 import `toml`，pip 25 / setuptools editable 会进入隔离构建环境；补充 `pyproject.toml` 的 build requirements 后安装成功。
- 日志中有 `Warp CUDA error: Failed to get driver entry point 'cuDeviceGetUuid'` 启动 warning，以及大量 IsaacLab 2.2 `quat_rotate` / `quat_rotate_inverse` deprecation warning；本次无 Python traceback，进程返回码为 0。
- 本地已回收远端实验归档，`日志/运行日志.txt` 约 4.1MB，`检查点/` 约 189MB。

## 后续处理

- 继续运行更长步数的云端训练速度测试，建议先保留 `Wandb.Mode: disabled`，确认吞吐和显存占用后再开启在线记录。
- 视需要在 SurgicalRobot5 代码中逐步替换 IsaacLab 2.2 已弃用的 `quat_rotate` / `quat_rotate_inverse` 调用，降低日志噪声。
