# 危险区域世界模型50比50采样

## 实验目的

当前旧实验显示 dual rollout 下世界模型预测误差显著高于 main rollout，且 `WorldModelBatch/source_dual_ratio` 全程平均约为 23.5%。本实验将世界模型 replay 采样改为全 batch 维度的 50% uniform + 50% safety-critical，验证危险区域建模是否改善。

## 实验假设

- 原实现按 `per_env_batch` 取整，在 `BatchSize == NumEnvs` 时会让 `SafetyCriticalRatio=0.45` 实际退化为 0。
- 修复为全 batch 配额后，`WorldModelBatch/source_dual_ratio` 和 high/boundary cost 覆盖率应明显提升。
- 在保留 50% uniform 数据的前提下，训练稳定性应优于 dual-only 或高权重 loss 的激进方案。

## 运行命令

```bash
bash experiments/2026-06-11_危险区域世界模型50比50采样/运行命令.sh
```
