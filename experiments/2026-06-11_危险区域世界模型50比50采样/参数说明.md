# 参数说明：危险区域世界模型50比50采样

## 核心参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| `WorldModelSampling.EnableSafetyCriticalSampling` | `true` | 启用世界模型 replay 的 safety-critical 混合采样 | 本实验保持开启 |
| `WorldModelSampling.SafetyCriticalRatio` | `0.50` | 每个 world model batch 中目标 safety-critical 序列比例 | 若训练不稳可降到 `0.35`；若 dual 误差仍高可升到 `0.60` |
| `WorldModelSampling.UniformRatio` | `0.50` | 实验语义上的 uniform 采样比例 | 当前代码实际使用 `SafetyCriticalRatio` 计算，保留该字段便于记录 |
| `WorldModelSampling.HighCostThreshold` | `0.1` | high-cost safety 窗口判定阈值 | 若 high-cost 过少可下调 |
| `WorldModelSampling.BoundaryLow / BoundaryHigh` | `0.05 / 0.4` | boundary-cost safety 窗口区间 | 与默认 world model safety 采样保持一致 |

## 观测指标

| 指标 | 期望变化 | 说明 |
|---|---|---|
| `WorldModelBatch/source_dual_ratio` | 后期接近或高于 `0.40` | 说明 world model batch 中 dual 数据占比显著高于旧实验 |
| `WorldModelBatch/high_cost_ratio` | 上升 | 说明危险/边界区域样本进入世界模型更新更多 |
| `Replay/source_dual_ratio` | 不一定大变 | 本实验不先激进调整 dual 采集比例 |
| dual rollout 预测误差 / main rollout 预测误差 | 从接近 `5x` 下降 | 判断危险区域建模是否改善的核心依据 |

## 设计取舍

- 本实验使用 `configs/reachability_gp_isaaclab22_4090_fast.yaml` 作为基座，以避免默认训练频率导致单次长训接近 12 小时。
- 本实验只修复 world model 采样比例，不同时增加 source-aware loss，避免把稳定性风险叠得太高。
- 50% uniform 保留主策略分布，50% safety-critical 强化 dual/high-risk/boundary 区域。
- 如果训练稳定但 dual 误差仍明显偏高，下一步再考虑 world model 的 dual source loss weight。

## 4090 fast 基座参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| `JointTrainAgent.NumEnvs` | `128` | 并行环境数 | 若显存不足可降回 `64` |
| `JointTrainAgent.BatchSize` | `256` | replay 更新 batch 序列数 | 需保持 `BatchSize >= NumEnvs` 且可整除 |
| `JointTrainAgent.ImagineBatchSize` | `256` | imagination 更新 batch 数 | 若显存不足可降到 `128` |
| `JointTrainAgent.TrainModelEverySteps` | `1024` | world model 更新间隔 | fast 模式降低更新频率以提升 wall-clock 吞吐 |
| `JointTrainAgent.TrainAgentEverySteps` | `1024` | agent / critic 更新间隔 | 与 world model 更新间隔对齐 |
| `JointTrainAgent.ModelUpdate` | `2` | 每次触发的 world model 更新次数 | 默认配置为 `4`，fast 模式降为 `2` |
| `JointTrainAgent.AgentUpdate` | `2` | 每次触发的 agent 更新次数 | 默认配置为 `4`，fast 模式降为 `2` |
