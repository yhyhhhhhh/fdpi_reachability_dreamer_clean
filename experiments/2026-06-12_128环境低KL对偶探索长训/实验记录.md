# 实验记录：128环境低KL对偶探索长训

## 实验目的

当前 64 env 的 baseline engineering + dual KL 0.1 版本学习设置较稳，但 RTX 4090 利用率仍有空间。本实验将 `NumEnvs`、`BatchSize` 和 `ImagineBatchSize` 提高到 `128`，同时保留 baseline 的更新触发频率和更新步数，验证能否在不明显削弱策略学习的情况下提高硬件利用率。

## 配置摘要

- 基础配置：`configs/reachability_gp_isaaclab22_baseline_engineering_dual_kl01.yaml`
- 实验配置：`configs/reachability_gp_isaaclab22_baseline_engineering_dual_kl01_128env.yaml`
- `NumEnvs=128`
- `BatchSize=128`
- `ImagineBatchSize=128`
- `TrainModelEverySteps=256`
- `TrainAgentEverySteps=256`
- `ModelUpdate=4`
- `AgentUpdate=4`
- `Gp/Gd/Dual UpdateSteps=2`
- `Gd/DualSampling/DualUpdate StartStep=1000000`
- `DualUpdate.KLCoeff=0.1`

## 与 fast 配置的区别

这组实验不采用 fast 配置的低更新比例。之前 fast 模式主要把 `Train*EverySteps` 放大到 `1024` 且降低多路 update steps，策略学习能力明显变弱；本实验保持每 `256 env steps` 更新一次，并保留 agent 更新强度，只提高环境并行和 batch。
