# 参数说明：4090策略更新强度恢复验证

## 核心参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| `NumEnvs` | `128` | 并行环境数，继续利用 4090 的环境吞吐 | 若显存或 IsaacSim 不稳定，回退 `64` |
| `BatchSize` | `256` | world model / critic replay batch 序列数 | 必须 `>= NumEnvs` 且能被 `NumEnvs` 整除 |
| `ImagineBatchSize` | `256` | agent imagination batch 数 | 必须 `>= NumEnvs` 且能被 `NumEnvs` 整除 |
| `TrainModelEverySteps` | `512` | world model 更新触发间隔 | fast 为 `1024`；本实验恢复更多更新 |
| `TrainAgentEverySteps` | `512` | agent 更新触发间隔 | fast 为 `1024`；本实验重点恢复策略学习 |
| `ModelUpdate` | `2` | 每次触发 world model 更新次数 | 低于 baseline 的 `4`，保留吞吐 |
| `AgentUpdate` | `4` | 每次触发 agent 更新次数 | 恢复到 baseline 单次触发强度 |
| `Gp/Gd/Dual UpdateSteps` | `2` | 风险 critic 与 dual policy 每次触发更新次数 | 从 fast 的 `1` 恢复为默认强度 |
| `SampleMaxSteps` | `10000000` | 长训总环境步数 | 先在 W&B 观察 1M 附近是否恢复夹取，训练默认继续到 10M |

## 设计动机

- 原始 baseline 大约每 `1024 env steps` 有 `16` 次 agent update，用户观察约 `1M env steps` 已能学会夹取。
- 4090 fast 大约每 `1024 env steps` 只有 `2` 次 agent update，W&B 观察接近 `4M env steps` 仍未学会夹取，策略学习明显过弱。
- policy recovery 大约每 `1024 env steps` 有 `8` 次 agent update，保留 `128 env + batch 256 + AMP/TF32`，但把策略学习强度拉回 fast 与 baseline 中间。

## 重点观察

| 指标 | 观察目的 |
|---|---|
| reward / success / grasp 相关指标 | 判断夹取是否能在 1M 附近恢复 |
| `Agent/actor_loss`、`Agent/critic_loss`、`MainFDPI/entropy` | 判断策略更新是否更有效且熵没有异常塌缩 |
| `WorldModel/*loss` | 判断增加更新频率后世界模型是否稳定 |
| `Gp/*`、`Gd/*`、`Dual/*` | 判断风险 critic 与 dual policy 是否跟得上主策略变化 |
| timing 指标 | 估算恢复更新强度后的真实 wall-clock 训练时间 |

## 与 fast 的差异

| 项目 | 4090 fast | policy recovery |
|---|---:|---:|
| `TrainModelEverySteps` | `1024` | `512` |
| `TrainAgentEverySteps` | `1024` | `512` |
| `AgentUpdate` | `2` | `4` |
| `Gp.UpdateSteps` | `1` | `2` |
| `Gd.UpdateSteps` | `1` | `2` |
| `DualUpdate.UpdateSteps` | `1` | `2` |
| `SaveEverySteps` | `2000000` | `1000000` |
