# 实验记录：低KL对偶探索诊断

## 实验目的

当前 W&B run `yygyodz1` 显示 dual 数据占比约 `20%`，但 `Replay/dual_cost_rate` 没有高于 `Replay/main_cost_rate`。本实验将 `DualUpdate.KLCoeff` 从 `1.0` 降到 `0.1`，并新增 dual-main 动作距离诊断，验证对偶策略是否只是被 KL 约束压回主策略附近。

## 配置摘要

- 基础配置：`configs/reachability_gp_isaaclab22_baseline_engineering.yaml`
- 实验配置：`configs/reachability_gp_isaaclab22_baseline_engineering_dual_kl01.yaml`
- 关键变化：`FDPIRegimeDreamer.DualUpdate.KLCoeff=0.1`
- dual 启动时机：`DualSampling.StartStep=1000000`，`DualUpdate.StartStep=1000000`
- 新增诊断：`DualAction/rollout_*` 与 `Dual/*_to_main*`

## 运行命令

```bash
bash experiments/2026-06-12_低KL对偶探索诊断/运行命令.sh
```

tmux 长训入口：

```bash
bash experiments/2026-06-12_低KL对偶探索诊断/启动tmux长训.sh
```

## 待观察问题

- `Replay/dual_cost_rate` 是否在 dual 启动后超过 `Replay/main_cost_rate`。
- `DualAction/rollout_mean_l2` 和 `DualAction/rollout_sample_l2` 是否相对 KL=1.0 对照明显增大。
- `Dual/kl_loss` 是否仍远大于 `Dual/policy_loss`。
- 降低 KL 后是否出现明显训练不稳定、任务 reward 下降或 dual KL 失控。
