# 参数说明：128环境KL003对偶探索诊断

## 核心原则

本实验只降低对偶策略 KL 权重，不切换 `DualUpdate.Type`，也不改变 128 env 版本的训练更新密度。

## 关键对照

| 参数 | 当前值 | 对照值 | 含义 | 修改建议 |
|---|---:|---:|---|---|
| `DualUpdate.Type` | `imagined_risk_return` | `imagined_risk_return` | 保持原有对偶策略目标，避免引入目标函数变化。 | 本组先不改为 `max_risk`。 |
| `DualUpdate.KLCoeff` | `0.03` | `0.1` | 对偶策略贴近主策略的 KL 权重。 | 若 dual 真实危险率仍低且 KL 未失控，再考虑 `0.01`。 |
| `DualSampling.MaxKLForSampling` | `400.0` | `400.0` | dual 与主策略偏离过大时停止混入 dual action。 | 若 KL 很快接近上限，需要单独诊断。 |
| `DualSampling.StartStep` | `1000000` | `1000000` | dual 采样启用步数。 | 保持不变，避免过早影响主策略学习。 |
| `DualUpdate.StartStep` | `1000000` | `1000000` | dual policy 更新启用步数。 | 保持不变。 |
| `WorldModelEval.Enable` | `true` | `false` | 开启低频 world model 诊断，用于比较 main / dual 分布预测误差。 | 若只想复现实验旧行为，可一键改为 `false`。 |
| `WorldModelEval.EverySteps` | `1000000` | `1000000` | 每 1M env steps 左右评估一次，避免高频拖慢训练。 | 若做短 smoke test，可临时降到 `1024`。 |

## 观察指标

| 指标 | 关注点 |
|---|---|
| `Dual/kl_loss` 与 `Dual/policy_loss` | KL 项是否仍显著大于风险探索项。 |
| `Dual/kl_to_main` | dual 是否偏离主策略过快，是否接近 `MaxKLForSampling=400`。 |
| `Replay/dual_cost_rate` 与 `Replay/main_cost_rate` | dual 真实危险率是否超过 main，这是本实验核心判断。 |
| `RecentCost/dual_binary_cost_rate` 与 `RecentCost/main_binary_cost_rate` | 最近窗口内 dual / main 的真实 binary cost rate，更适合判断当前 dual 是否更危险。 |
| `RecentCost/dual_continuous_cost_mean` 与 `RecentCost/main_continuous_cost_mean` | 最近窗口内 dual / main 的 continuous cost 均值，避免被 1M 前 replay 历史污染。 |
| `Dual/real_cost_mean` | dual action 当前 rollout 的真实 cost 是否上升。 |
| `DualAction/rollout_sample_l2` | dual 与 main 的动作样本距离是否比 KL 0.1 更大。 |
| `Rollout/episode_success_rate` | 降低 KL 后是否明显干扰主策略任务学习。 |
| `WMEval/main/*` 与 `WMEval/dual/*` | 比较 world model 对主策略与对偶策略数据分布的 posterior / prior / open-loop 预测精度。 |
| `WMEvalGap/dual_minus_main/*` | 直接观察 dual 分布相对 main 分布的误差差距。 |

## 停止或继续标准

- 若 `Replay/dual_cost_rate` 长期仍低于 `Replay/main_cost_rate`，说明仅降低 KL 可能不足。
- 若 `Dual/kl_to_main` 快速接近 `400` 且任务学习被破坏，应停止并考虑更温和的 KL 或采样比例控制。
- 若 dual 危险率明显上升且主策略学习未明显退化，可继续长训观察 world model / Gp 是否受益。
- 若 `WMEval/dual/openloop_h10_cost_mae`、`WMEval/dual/prior1/dyn_kl` 明显高于 main，说明对偶分布仍是 world model 的困难区域。
