# 参数说明：baseline工程优化长训

## 运行参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| `CONFIG_PATH` | `configs/reachability_gp_isaaclab22_baseline_engineering.yaml` | 本实验主配置 | 默认不改 |
| `RUN_NAME` | `fdpi-baseline-engineering` | checkpoint 与 W&B run 名称前缀 | 多次重复实验可通过 `RUN_ID` 区分 |
| `RUN_ROOT` | `experiments/2026-06-12_baseline工程优化长训/检查点` | checkpoint 输出目录 | 不建议写到实验目录外 |
| `WANDB_MODE` | `online` | W&B 在线记录 | 临时离线可设为 `offline` 或 `disabled` |

## 训练参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| `NumEnvs` | `64` | 与 baseline 一致的并行环境数 | 为复现 baseline 学习能力，先不升到 128 |
| `BatchSize` | `64` | world model / critic replay batch | 与 `NumEnvs` 相等，满足 replay sampling 约束 |
| `ImagineBatchSize` | `64` | actor/critic imagination context batch | 与 baseline 一致 |
| `TrainModelEverySteps` | `256` | world model 更新触发间隔 | 与 baseline 一致 |
| `TrainAgentEverySteps` | `256` | agent/Gp/Gd/dual 更新触发间隔 | 与 baseline 一致 |
| `ModelUpdate` | `4` | 每次触发的 world model optimizer step 数 | 与 baseline 一致 |
| `AgentUpdate` | `4` | 每次触发的主策略 optimizer step 数 | 与 baseline 一致 |
| `Gp/Gd/Dual UpdateSteps` | `2 / 2 / 2` | 风险 critic 与 dual policy 更新步数 | 与 baseline 一致 |

## 工程优化参数

| 参数 | 当前值 | 含义 | 修改建议 |
|---|---:|---|---|
| `AllowTF32` | `true` | 允许 4090 使用 TF32 matmul | 若怀疑数值差异，可设为 `false` 做对照 |
| `MatmulPrecision` | `high` | PyTorch float32 matmul 精度策略 | 保持 `high` |
| `LogEverySteps` | `4096` | 普通非关键日志频率 | 若需要更密曲线可降到 `1024` |
| `DetailedLogEverySteps` | `8192` | batch composition、force 细项等详细日志频率 | 保持低频，减少训练干扰 |
| `TimingLogEverySteps` | `8192` | 分阶段 timing 日志频率 | 保留，用于看工程优化是否生效 |
| `CacheReplayStarts` | `true` | 缓存 replay valid starts / safety starts | 保持开启 |
| `UseSampleMany` | `true` | 连续更新批量采样 replay batch | 保持开启 |
| `UseBatchedCriticLatentEncoding` | `true` | Gp/Gd/dual 共用批量 latent 编码路径 | 保持开启 |
| `FDPIGradDiagnosticsEverySteps` | `65536` | FDPI 梯度诊断低频计算 | 保持低频，避免额外反传开销 |

## 重点观察

- `Rollout/episode_success_rate` 是否在约 `1M env steps` 附近恢复。
- `Rollout/IsaacLab/*_reward` 是否接近旧 baseline 的上升速度。
- `Train/agent_update_ratio` 应接近 baseline，约 `0.0156`。
- `Timing/*` 中 replay sampling、latent encoding 和 update 阶段耗时是否低于未工程优化的 baseline。
