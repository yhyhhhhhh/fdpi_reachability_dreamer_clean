# 实验记录：128环境无FDPI无对偶采样基线

## 实验目的

当前需要判断引入 FDPI 和对偶策略采样是否让 world model 不再专注于主任务区域，从而降低主策略学习效果。本实验建立一个真实训练入口：不启用 FDPI，不混入 dual action，用同样的 128 env 训练密度做对照。

## 配置摘要

- 基础配置：`configs/reachability_gp_isaaclab22_baseline_engineering_dual_kl01_128env.yaml`
- 实验配置：`configs/reachability_gp_isaaclab22_baseline_engineering_no_fdpi_no_dual_128env.yaml`
- `NumEnvs=128`
- `BatchSize=128`
- `ImagineBatchSize=128`
- `TrainModelEverySteps=256`
- `TrainAgentEverySteps=256`
- `ModelUpdate=4`
- `AgentUpdate=4`
- `MainFDPIRegime.Enable=false`
- `Gp.Enable=false`
- `Gd.Enable=false`
- `DualSampling.Enable=false`
- `DualUpdate.Enable=false`
- `WorldModelEval.Enable=true`

## 运行命令

```bash
bash experiments/2026-06-12_128环境无FDPI无对偶采样基线/启动tmux长训.sh
```
