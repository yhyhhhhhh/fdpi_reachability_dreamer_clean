# 参数说明：128环境无FDPI无对偶采样基线

## 核心原则

本实验是“真实训练 baseline”：保持当前 128 env baseline-engineering 的训练密度，只关闭 FDPI 和对偶采样相关机制，让主策略按普通 Dreamer actor-critic 目标学习。

## 关键开关

| 参数 | 当前值 | 对照值 | 含义 | 修改建议 |
|---|---:|---:|---|---|
| `MainFDPIRegime.Enable` | `false` | `true` | 关闭主策略 FDPI regime，主策略不再按 feasible / critical / infeasible 风险区间重加权 reward 和安全项。 | baseline 固定为 `false`。 |
| `Gp.Enable` | `false` | `true` | 关闭主策略 reachability critic 的采样与更新，并且训练循环不会把 Gp 传给主策略 FDPI 更新。 | 若只想“无 dual 但保留 FDPI”，应另建配置，不在本 baseline 中打开。 |
| `Gd.Enable` | `false` | `true` | 关闭 dual 采样所需的高风险 critic 更新。 | baseline 固定为 `false`。 |
| `DualSampling.Enable` | `false` | `true` | rollout 不混入 dual policy action，replay 中 `source` 应全部为 main。 | baseline 固定为 `false`。 |
| `DualUpdate.Enable` | `false` | `true` | 不更新 dual policy。 | baseline 固定为 `false`。 |
| `WorldModelEval.Enable` | `true` | `true` | 保留低频 world model 评估，和 FDPI+dual run 使用同一套诊断指标。 | 若显存或耗时敏感，可临时改为 `false`。 |

## 预期验证指标

| 指标 | 预期 | 作用 |
|---|---|---|
| `MainFDPI/enabled` | `0` | 确认主策略没有进入 FDPI regime。 |
| `Dual/source_count` | `0` | 确认当前 rollout 没有 dual action。 |
| `Replay/source_dual_ratio` | `0` | 确认 replay 分布没有 dual 来源数据。 |
| `Train/gp_updates` | `0` | 确认 Gp critic 没有更新。 |
| `Train/gd_updates` | `0` | 确认 Gd critic 没有更新。 |
| `Train/dual_updates` | `0` | 确认 dual policy 没有更新。 |
| `Rollout/episode_success_rate` | 与 FDPI+dual 对比 | 判断关闭安全侧机制后任务学习是否更快。 |
| `WMEval/main/*` | 与 FDPI+dual 的 main split 对比 | 判断无 dual 分布干扰时 world model 对主任务区域的预测质量。 |
| `WMEval/dual/sample_count` | `0` 或低于阈值 | 无 dual 采样时该 split 不应有足够样本。 |

## 对照方式

- 与 `experiments/2026-06-12_128环境KL003对偶探索诊断/` 对比任务学习速度和 world model 误差。
- 重点看同一 env steps 下的 `Rollout/episode_success_rate`、`Main/task_return`、`WMEval/main/prior1/dyn_kl`、`WMEval/main/openloop_h10/cost_mae`、`WMEval/main/openloop_h15/reward_mae`。
- 如果本 baseline 明显更快学会任务，而 FDPI+dual 的 `WMEval/main/*` 更差，可以支持“对偶采样改变数据分布，削弱主任务区域建模”的假设。
